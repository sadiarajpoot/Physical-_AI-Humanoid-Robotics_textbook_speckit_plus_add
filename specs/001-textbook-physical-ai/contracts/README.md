# Contracts: AI/Spec-Driven Textbook for Physical AI & Humanoid Robotics

## Project Type: Static Site

This project is implemented as a static site using Docusaurus, with no server-side API required. All content is delivered as static files served through GitHub Pages or Vercel.

## Frontend Interactions

The site provides the following user interactions through static content:

1. **Content Navigation**: Users can navigate through the textbook using the sidebar
2. **Content Display**: Content is displayed as structured Markdown pages
3. **Responsive Design**: Content adapts to different screen sizes
4. **Search Functionality**: Built-in Docusaurus search for finding content

## No API Contracts Required

Since this is a static site:
- No server-side endpoints
- No API authentication
- No data persistence layer
- No real-time interactions
- All content served as static files

## Deployment Artifacts

The build process generates:
- Static HTML files for each content page
- CSS and JavaScript bundles for functionality
- Asset files (images, documents)
- Search index for site search
